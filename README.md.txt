# STUDIO58 - LIMADELAPAN STUDIO DIGITAL

Platform pembelajaran **Mastering Digital Animation with AI** berbasis web statis.

## Fitur Utama
- Landing page modern (Dark Glassmorphism UI)
- Sistem Login Member Area (`localStorage` / `sessionStorage`)
- 15+ Modul Pembelajaran Video AI dengan pencarian *real-time*
- Modal detail interaktif berisi 2 video player (Contoh Video & Video Tutorial)
- Fitur *Salin Ringkasan Modul* dan tautan tools pendukung

## Teknologi
- HTML5
- Tailwind CSS (CDN v3)
- FontAwesome 6.4 & Google Fonts (Plus Jakarta Sans)
- Vanilla JavaScript
